---
title: Plan and Execute Tasks in Board and List
description: Create tasks, set metadata, and execute work using Board and List views
---

Use this workflow to move from planning to execution with minimal overhead.

## 1. Create tasks quickly

In a project:

1. Open **Board** or **List** view.
2. Click **Create task**.
3. Add a short, action-oriented title.
4. Optionally set description, assignee, priority, due date, and labels.

## 2. Keep task data clean

When editing tasks, prioritize:

- Clear scope in the description
- One owner (assignee)
- Explicit priority
- Realistic due dates
- Reusable labels

## 3. Execute in Board view

Board view is best for flow-based execution:

1. Pull tasks into active columns.
2. Drag tasks across columns as status changes.
3. Open a task to edit details without losing board context.

## 4. Switch to List view for dense review

List view is useful when you need to scan many tasks quickly.

Typical uses:

- Reviewing priorities across the project
- Spotting overdue work
- Finding unassigned or under-specified tasks

## 5. Use filters to focus

The board toolbar supports filtering by:

- Status
- Priority
- Assignee
- Due date
- Labels

Use filters aggressively during standups, planning, and triage.

When a filter has at least one value selected, the board toolbar renders a filter chip for that field, in the same left-hand row as the **Filter** button and the sort control, appearing after them. The row wraps onto a new line when it runs out of width. Each field gets at most one chip, never one chip per selected value, and chips appear in this order: Status, Priority, Assignee, Due date, Labels.

Each chip has four divider-separated segments: the subject (the field name), the operator, the value, and an X control.

Status, Priority, Assignee, and Due date chips use the operator "is any of"; the Labels chip uses "include any of". The value depends on the field:

- Status shows up to three column icons, then the column name when one value is selected, or a count such as "3 selected" when two or more are.
- Priority shows up to three priority icons, then the priority name when one value is selected, or a count such as "3 selected" when two or more are.
- Assignee shows up to three member avatars, then the member name when one value is selected, or a count such as "3 selected" when two or more are.
- Due date shows no icons, and reads Due this week, Due next week, or No due date when one value is selected, or a count such as "3 selected" when two or more are.
- Labels shows no icons and always a count, never a label name: "1 selected" for one label, "3 selected" for three. A single entry in the Labels list covers every workspace label that shares its name and color, so selecting one entry can produce a count higher than one.

Icon previews stop at three regardless of how many values are selected.

Clicking a chip's X clears that field's entire selection, not one value at a time. For all five fields, including Labels, the chip disappears and every value selected for that field is removed. The X never affects the other chips; their filters are left untouched.

To clear everything at once, open the **Filter** menu and choose **Clear all filters**, the last item, below a separator. It's shown only while at least one filter is active.

## 6. Open full task page when needed

From the task sheet, use **Open in full page** for deeper edits and focused context.
